# Thư Mục Thiết Kế Kỹ Thuật (05-tech)

Thư mục này ghi lại kiến trúc hệ thống, quy trình tích hợp mô hình trí tuệ nhân tạo và thiết kế dữ liệu của ứng dụng Tiệm May Nếp trên nền tảng Google AI Studio.

## Danh sách tài liệu

- `docs/05-tech/architecture.md`: Kiến trúc tổng thể hệ thống, sơ đồ luồng dữ liệu Mermaid, cơ chế bảo vệ `GEMINI_API_KEY` qua máy chủ proxy Express nội bộ, chi tiết 4 điểm tích hợp Gemini, cơ chế Palette Swapping nhân vật pixel 64x96, mô tả trường dữ liệu catalog và chính sách bảo vệ dữ liệu cá nhân.
